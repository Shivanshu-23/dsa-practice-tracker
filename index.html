How to use this. Work one pattern at a time, in order — the list within each pattern is ordered easy → hard on purpose. Give every problem 45 minutes before looking at anything, and when you do look, read only the approach, then close it and write the code yourself. Anything you needed help with goes on a re-solve list for day 3 and day 14.

Checkboxes save automatically — progress is stored in this browser (localStorage), so it survives reloads and closing the tab. It's tied to this browser/device only, so it won't follow you to a different computer or a private/incognito window — for that, keep your own sheet with the columns from the log template.
